# Scientific provenance

This public release contains the corrected finite-chain computational study and its earlier foundation exercises. It preserves the retained numerical CSV/JSON data, figures and regression input from the checked baseline. Personal working material and correspondence are not part of the public scientific package.

The model and numerical analysis were developed with AI assistance. Teaching text and notebook explanations also received AI assistance. Automated checks support numerical implementation; they do not establish independent authorship, experimental validation or novelty. No publication, institutional endorsement or coauthorship agreement is implied.

The scientific history includes a correction from an even-only size scan to all N=4 through 12, a correction of the staggered diagnostic for odd N, and a more careful interpretation of low-energy states using configuration probabilities. The corrected evidence is retained. Earlier overbroad interpretations are not presented as current conclusions.

The public Python changes remove local filesystem paths and personal narrative from generated validation prose; computational expressions are unchanged. The two notebooks retain their scientific code and explanations, with cleaned narrative and freshly generated outputs. Their filenames and metadata are public-facing. The bundled reference data remains immutable and independent of any private directory.

External research is cited through primary-source links. The code uses NumPy, SciPy, Matplotlib and Qiskit; dependency packages retain their own licences. Full external repositories, paper PDFs and downloaded research datasets are not redistributed. No new licence is assigned to the project by this release preparation.
